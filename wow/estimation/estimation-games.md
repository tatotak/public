# Estimation Games

**General tips:** randomize task order, avoid bias, involve different functions.

## Planning Poker

Online tool: [planning-poker-agile.web.app](https://planning-poker-agile.web.app/game/)

1. Everyone gets bucket cards.
2. PO reads out the task description.
3. Team discusses briefly to clarify scope.
4. Each member privately picks a card with their estimate.
5. Cards are revealed simultaneously.
6. If there's a large spread, outliers explain their reasoning.
7. Repeat until consensus is reached.

## Silent Sort

1. Place all tasks on a single pile.
2. Silently arrange tasks on a scale from smallest to biggest.
3. Take turns - each member can pass, rate, adjust or flag an item.
4. Discuss flagged items.
5. Group cards into buckets - take turns, stay silent.

## Affinity Estimation

1. Form buckets.
2. Each member can move a task into a bucket or flag an item.
3. Discuss flagged items.

## Bucket System

1. Form buckets.
2. **Add one reference example to each bucket - critical.**
3. Group remaining tasks into buckets.
4. Discuss at the end.

## Voting System

1. Show tasks.
2. Each member gets votes (e.g. 1 big, 2 medium).
3. Each member places votes on items they believe are complex (max 1 vote per item).
4. Highest-voted tasks are considered the most complex.
5. Repeat if needed.

## Three-Point Estimation

Optimistic, Likely, Pessimistic.

1. Form tasks.
2. Each member proposes 3 buckets per story: Optimistic (O), Likely (L), Pessimistic (P).
3. PO calculates the estimate with the PERT formula: `PERT = (O + 4L + P) / 6`
